Questions & Answers

Frequently Asked Questions

Everything you need to know about Mesh Notes, privacy, and how it works.

Is Mesh Notes really 100% free and open source?

Yes, completely. There are no paid tiers, no "Pro" features, no paywalls, and no credit card required. All 5 productivity apps (Code Vault, Daily Habits, Finance & Domains, Flashcards, Highlights) are unlocked for all users forever.

Where is my data stored? Does Mesh Notes use cloud servers?

All your data is stored locally on your machine or private server inside a single SQLite database file (mesh-notes.db). Mesh Notes does not send your notes or telemetry to any external cloud provider. You have complete data sovereignty.

How does the domain and expense tracker handle multiple accounts?

When you purchase domains or subscriptions from multiple providers (e.g., Cloudflare, Namecheap, AWS, Google Domains), you often use different login emails. Mesh Notes allows you to explicitly specify the associated login email for each service so you always know which credentials own which asset. It also supports INR (₹), USD ($), EUR (€), JPY (¥), CNY (¥), and RUB (₽).

Can I use Mesh Notes offline without an internet connection?

Yes. Mesh Notes is built with Progressive Web App (PWA) capabilities and runs locally on your computer. You can write notes, review flashcards, check off daily habits, and perform full-text searches without any internet connection.

How do I back up or export my notes?

Mesh Notes supports 1-click universal backup exports. You get a downloadable zip file containing all your notes as standard Markdown files with YAML frontmatter, and all your saved bookmarks as standard Netscape HTML compatible with every browser. You can also back up your data simply by copying the mesh-notes.db file.

How does the Burn-After-Reading secret sharing work?

When you need to share a sensitive note (such as a server credential or private memo), you can generate a share link with the "Burn After Reading" option enabled. As soon as the recipient opens and reads the note, the server permanently purges the share record from the database. It cannot be accessed a second time.
