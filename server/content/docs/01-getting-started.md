# Welcome to Mesh Notes

Mesh Notes is your private, distraction-free space for taking quick notes, saving web bookmarks, and keeping your daily life organized. It runs completely locally on your machine or private server.

> [!TIP]
> Mesh Notes is **100% free and open source**. There are no premium plans, no paywalls, and no locked features. Everything is available to everyone from day one.

---

## What makes Mesh Notes different?

Most modern note apps are either bloated with enterprise project management features you never use, or they trap your data in proprietary cloud databases with recurring monthly subscriptions.

Mesh Notes takes a different approach:
- **Fast and lean**: Built to capture thoughts in 2 seconds.
- **Unified Stream**: Fleeting thoughts, structured markdown notes, and saved web bookmarks live together in one clean, searchable feed.
- **Single File Storage**: All your notes, tags, and settings are stored in a standard SQLite database file (`mesh-notes.db`) on your disk.
- **5 Built-in Productivity Apps**: Code Vault, Daily Habits, Finance & Domain Tracker, Flashcards, and Highlights Inbox.

---

## Writing Your First Note

1. Click **Open App** or navigate to `/app`.
2. Type whatever is on your mind in the composer box at the top.
3. Use `#tags` directly in your text (for example: `#ideas`, `#project`, `#todo`). Mesh Notes automatically indexes hashtags so you can filter by them in the left sidebar.
4. Press `Cmd + Enter` (or `Ctrl + Enter`) to save.

---

## Saving Web Bookmarks & Clean Reading

Whenever you paste any web link (like `https://github.com` or an article URL), Mesh Notes automatically unfurls the title, description, and preview image.

Click the book icon on any saved article to open **Reader Mode**:
- St剝 stripped of all banner ads, popups, and cookie consent banners.
- Shows estimated reading time.
- Allows you to highlight any passage with your mouse and click **Save Highlight** to file it into your Quotes Inbox.

## Keyboard Shortcuts

Work quickly without lifting your hands from the keyboard:

| Shortcut | Action |
|---|---|
| `Cmd + K` or `Ctrl + K` | Open Quick Search to find any note or bookmark instantly |
| `Cmd + Enter` or `Ctrl + Enter` | Save / Submit active note |
| `Cmd + B` / `Ctrl + B` | Bold selected text |
| `Cmd + I` / `Ctrl + I` | Italic selected text |
| `Cmd + E` / `Ctrl + E` | Format as inline code |
| `/` in empty line | Open Notion-style command menu (tables, headings, checklists) |
